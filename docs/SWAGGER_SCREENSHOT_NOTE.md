# Swagger UI Screenshot

Run the backend and open:

`http://localhost:8080/swagger-ui/index.html`

Take a screenshot showing the Users, Study Groups, and Study Sessions endpoints. Save it in this folder as:

`swagger-ui.png`

The static OpenAPI file is available in `docs/openapi.yaml`. Spring Boot also generates live OpenAPI JSON at:

`http://localhost:8080/v3/api-docs`
